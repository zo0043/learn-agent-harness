### P9｜（Lead 补充，专家未覆盖）课程把 `trajectories/demo.jsonl` 当「实测」引用，而该文件不在版本控制里

- **严重度**：medium
- **对象**：`notes/observability.md:139`/`:352`、`notes/multi-agent.md:268`（均引用 `harness-demo/trajectories/demo.jsonl` 的实测内容）；`.gitignore:19-20`（`harness-demo/trajectories/*` + 仅放行 `demo.example.jsonl`）
- **现象**：课程引用 `demo.jsonl` 的 22 行实测分布（`init×1 / model_response×6 / tool_intent×6 / tool_exec×8 / final×1`），但 **`demo.jsonl` 从未进库**：`git ls-files harness-demo/trajectories/` 只有 `demo.example.jsonl`，`git archive HEAD` 也只产出它。本地两份同为 9645 字节、事件分布一致，但 **md5 不同**（`4935c417…` vs `4012e7fa…`）——即进库的那份与本地"实测"那份并非同一文件内容。
- **证据**（Lead 实跑）：
  ```bash
  git ls-files harness-demo/trajectories/          # → harness-demo/trajectories/demo.example.jsonl
  git archive HEAD | tar -t | grep trajectories/   # → demo.example.jsonl（唯一）
  md5sum harness-demo/trajectories/demo{,}.jsonl   # → 4935c417… / 4012e7fa…（不同）
  node -e '…统计 kind 分布…'                        # → 两份均 22 行：init×1 model_response×6 tool_intent×6 tool_exec×8 final×1
  ```
- **影响**：读者 clone 后按笔记给的路径去读 `demo.jsonl` **找不到文件**（只有 `.example`）；而笔记数字本身在 `.example` 里成立，所以这是"引用路径不可达"而非"数字造假"。与 `TECH-A-F1` 同属「判据引用了一个 clone 后不存在的文件」，但危害更低。
- **建议方向**：把引用改为入库的 `demo.example.jsonl`（或说明 `demo.jsonl` 由 `npm run demo` 生成）；若两份应内容一致，加一条断言或消除差异。
- **置信度**：高（四条命令均为 Lead 亲自实跑，结论限于"文件不在库里 + 两份不一致"，不涉及数字真伪）。
