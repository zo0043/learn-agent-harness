# 毕业项目（生成层收口）

> **一句话纪律：本页不提供 starter / TODO / 参考答案，学员从空目录起步。**

这是主线 `my-agent` M0–M4 之后的第三跳：从「补全已知模块」跳到「从模糊需求，自己拆模块、定接口、写验收」。

## 三步技能层级

| 层 | 练什么 | 你拿到什么 | 判据来源 |
|---|---|---|---|
| ① 追踪（track） | 看懂确定性 demo | 完整可跑源码 | demo 自带断言 |
| ② 补全（complete） | 把 TODO 补对 | `starter` + `solution` | `assert:m<N>` 三态 |
| ③ **生成（generate）** | **从模糊需求自己设计实现** | **只有命题 + 判据 + 引导** | **你自己的 `assert.mjs` + `MANIFEST.md`** |

## 三个命题（选一条；想叠加两条算加分项）

命题完整描述、判据锚点、白盒要素侧重见 `notes/capstone-final.md` §3：

- **A · research-assistant**（个人研究助理）：查资料 → 记笔记 → 定时提醒，带权限门 / 可自评 / 可恢复。
- **B · repo-guard**（仓库巡检门禁）：读变更 → 跑检查 → 写报告 → 放行/拦截，带沙箱边界 / golden 评测 / 可观测。
- **C · signal-arbiter**（带噪信号方向判断器）：带噪 label 两轮降噪 → 门禁提案，带飞轮 / 模型意识 / 可恢复。

（一句话骨架在 `subjects/a-research.md` / `b-repo-guard.md` / `c-signal-arbiter.md`。）

## 验收判据（黑盒 B1–B5 + 白盒 W1–W7）

机器可读唯一真源在 `rubric.mjs`，逐字对照 `notes/capstone-final.md` §4。这里只放编号：

**黑盒（行为，可观察）**：B1 确定性 · B2 主任务跑通 · B3 权限/沙箱拦停 · B4 崩溃可恢复 · B5 评测自评。

**白盒（要素，只查「存在 + MANIFEST 指认」）**：W1 loop · W2 多工具 · W3 权限门 · W4 golden+断言 · W5 可恢复 · W6 可观测 · W7 M4 收口三选一。

## 怎么判自己过关（自测引导三步）

1. **先黑盒跑通**：断言一行都别写，先让成品对 2–3 个手工输入跑通（主场景 + 危险动作）。
2. **再白盒自查**：逐条写 `MANIFEST.md` 指认 W1–W7 的实现位置。
3. **再补断言**：把手工输入固化成确定性断言（B1–B5），连跑两次 `diff` 空。

## 判据运行入口

成品目录只需交两样东西：`assert.mjs`（黑盒断言，exit 0 = 过）+ `MANIFEST.md`（白盒自述，覆盖 W1–W7）。

```bash
node grade.mjs /path/to/你的成品目录   # 跑黑盒 + 白盒判据
# 或从仓库根：npm run check:final -- /path/to/你的成品目录
```

成品放哪都可以（如 `final-project/mine/`）。判据运行器只知道你的 `assert.mjs` + `MANIFEST.md` 两个接口，**不知道你内部怎么实现**——这正是生成层与补全层的分界。
