# 边缘缓存调研笔记（2026-Q3）

三个关键发现：

1. **命中率的天花板在缓存键设计**：同一页面 80% 的请求差异只在 region/ab-test 头，键里带上这两个字段命中率从 91% 掉到 64%。
2. **TTL 不是越大越好**：TTL 从 5min 提到 30min，命中率 +4pt，但脏数据投诉 ×6——TTL 要和"内容可被容忍的过期时间"对齐，而不是拍脑袋。
3. **预热比回源优化更值钱**：大促前对 Top 2000 SKU 主动预热，省下的回源带宽成本是预热存储成本的 11 倍。
